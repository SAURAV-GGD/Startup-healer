🚀 QUICK START (15 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Set Up Supabase (5 min)
    → Create account at supabase.com
    → Create new project
    → Run docs/database-schema.sql in SQL Editor
    → Copy URL and API keys

Step 2: Configure Environment (2 min)
    → cp .env.example .env
    → Edit .env with Supabase credentials and AI API key

Step 3: Install Dependencies (5 min)
    → Run: ./quick-start.sh
    OR manually:
    → npm install
    → cd backend && npm install
    → cd frontend && npm install
    → cd ai-service && pip install -r requirements.txt

Step 4: Start Application (1 min)
    → Run: npm run dev
    OR separately in 3 terminals:
    → cd backend && npm run start:dev
    → cd frontend && npm run dev
    → cd ai-service && uvicorn app.main:app --reload

Step 5: Access & Test (2 min)
    → Open http://localhost:3000
    → Sign up → Add startup → Run analysis!
